# Source availability and repository boundary

MoonShip's complete implementation is maintained privately in `Conor-711/MoonShipLab`. This public repository is a curated presentation of an implemented product, not a complete source distribution.

| Public material | Private implementation |
| --- | --- |
| Product descriptions and user journeys | Protocol and core smart-contract implementation |
| Feature and implementation-status summaries | Settlement, authorization and identity verification internals |
| Selected presentation-only frontend source | SDK internals and transaction controllers |
| Brand artwork and high-level diagrams | Issuance and revenue mechanisms and their detailed tests |
| Links to product entry points | Indexers, operational services, deployment tooling and full test suite |

The selected UI files are copied from the actual project and catalogued in `frontend/SOURCES.json`. They are excerpts; private dependencies and application controllers are intentionally absent. Generated application bundles, ABIs, source maps and compiled contracts are not distributed here.

Features identified as implemented have corresponding private implementation. Full source verification requires owner-granted access. Product availability, individual wallet actions, external adoption and independent security audit remain separate questions.

Changing repository availability cannot recall copies previously downloaded or otherwise lawfully retained. This change does not purport to revoke rights already granted under applicable earlier licenses. Existing third-party notices continue to apply to their respective material.
