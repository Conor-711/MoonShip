# Selected frontend presentation source

These are actual UI source excerpts from MoonShip. They expose selected visual presentation and iconography, without the protocol implementation, transaction controllers, private packages or services.

- `UiIcon.tsx`: the shared React SVG icon component.
- `styles/`: selected feed, posting, workspace and brand styles.
- `SOURCES.json`: original private-source paths and SHA-256 fingerprints for the copies.

This directory is not a standalone app and has no protocol execution backend. Use the live application to experience the implemented product, or request private repository access for a full build/review.
