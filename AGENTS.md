# MoonShip public repository context

This is MoonShip's curated public presentation repository. Read `README.md`,
`SOURCE_SCOPE.md` and `docs/IMPLEMENTATION_STATUS.md` to understand its scope.

The complete implementation is privately maintained in Conor-711/MoonShipLab.
Selected frontend files here are actual presentation-layer excerpts; core source
is intentionally excluded for privacy and intellectual-property protection.
Implemented/private-source labels describe the maintainer's recorded status.
Private-code review requires explicit access, and public documentation alone
cannot establish independent verification, adoption or a completed audit.

Do not add the private implementation, generated bundles, ABIs, source maps,
credentials, user data or operational configuration to this repository. There
is no complete local protocol/application build in this public snapshot.
